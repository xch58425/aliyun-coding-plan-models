## 用量规则：90,000 次/月扣的是模型调用次数，不是提问次数

额度按“模型调用次数”扣，一次提问往往对应多次调用——这一点官方文档写得清楚，但很容易被忽略。官方给的参考是：简单任务通常消耗 5–10 次调用，复杂任务 10–30 次甚至更多，取决于任务难度、上下文长度和工具调用情况。按简单任务折算，90,000 次/月大概对应几千个任务，单人开发通常够用；但如果你以为这是 9 万次提问，预期就会落空。

三重限额同时生效，任何一个触顶调用就暂停：

- **每 5 小时 6,000 次**：滚动恢复，比如 10 点用掉 100 次，15 点这 100 次自动回到可用额度里
- **每周 45,000 次**：每周一 0 点（北京时间）重置
- **每月 90,000 次**：按你的订阅日重置，跟自然月无关

日常交互式写代码，5 小时窗口基本碰不到顶；容易紧张的是多项目并行、长对话、频繁重新生成这类场景，调用次数会在后台悄悄堆起来。额度也没法攒着用——周一就把一周额度烧完，剩下几天只能等滚动恢复。

## 接入方式：专属 Key 加两行配置，接进你已有的工具

## 常见问题

**Lite 套餐还能买吗？**
不能。Lite 基础版 2026 年 3 月 20 日起停止新购，4 月 13 日起停止续费与升级。已购用户可以用到套餐到期，之后想继续只能转 Pro。Lite 之前支持的模型和 Pro 一致，差的主要是用量和价格。

**为什么订了套餐还在扣费？**
官方 FAQ 列的首要原因是 Key 用错了：套餐请求必须走 sk-sp- 开头的专属 Key 和 coding.dashscope.aliyuncs.com 的 Base URL，填成百炼通用 Key（sk- 开头）就会被按量计费扣余额。两套 Key 和 Base URL 不互通，也不要混用。

**额度用完了怎么办？**
等恢复。5 小时额度滚动释放，周额度每周一重置，月额度等订阅日。任何一个上限触顶，调用都会暂停，额度回来后自动可以继续。

**额度可以在多个工具之间共用吗？**
可以。额度跟着套餐 Key 走，只要用同一个 Key，在 Claude Code 里用掉的部分和 Cursor 里扣的是同一份额度，不需要为每个工具单独付费。

**这些模型的水平够用吗？**
两篇海外第三方测评的结论比较一致：日常的代码生成、补全、重构和调试，套餐内模型没问题；差距主要体现在最难的推理和架构级任务上，和第一梯队的 Claude、GPT 模型还有距离。把它当高性价比的日常主力更合适，别指望它在最难的问题上追平旗舰。
